# Task API

A small FastAPI service exposing CRUD endpoints over an in-memory list of tasks.

State lives in a Python list in [main.py](main.py), so **everything resets when the
process restarts**. There is no database.

## Install & run

From the repo root, with the bundled virtualenv:

```bash
flyrank\Scripts\Activate.ps1
fastapi dev
```

The API is then at `http://127.0.0.1:8000`. Interactive docs are generated by
FastAPI at `/docs` (Swagger UI) and `/redoc`.

If you'd rather set up your own environment:

```bash
python -m venv .venv && .venv/Scripts/activate && pip install "fastapi[standard]"
```

## Endpoints

| Method | Path          | Success        | Description                            |
| ------ | ------------- | -------------- | -------------------------------------- |
| GET    | `/`           | 200            | API name, version, and endpoint list   |
| GET    | `/health`     | 200            | Liveness check — `{"status": "ok"}`    |
| GET    | `/tasks`      | 200            | All tasks                              |
| GET    | `/tasks/{id}` | 200 / 404      | One task by id                         |
| POST   | `/tasks`      | 201 / 400      | Create a task from `{"title", "done"}` |
| PUT    | `/tasks/{id}` | 200 / 400, 404 | Replace a task's title and done flag   |
| DELETE | `/tasks/{id}` | 204 / 404      | Remove a task                          |

A task is `{"id": int, "title": str, "done": bool}`. `id` is assigned by the server;
request bodies only carry `title` (required) and `done` (defaults to `false`).

Errors come back as `{"error": "..."}`

## Example

```console
$ curl -i -X POST http://127.0.0.1:8000/tasks \
    -H "Content-Type: application/json" \
    -d '{"title":"Write README"}'
HTTP/1.1 201 Created
date: Tue, 21 Jul 2026 11:28:32 GMT
server: uvicorn
content-length: 44
content-type: application/json

{"id":4,"title":"Write README","done":false}
```

And a miss:

```console
$ curl -i http://127.0.0.1:8000/tasks/99
HTTP/1.1 404 Not Found
date: Tue, 21 Jul 2026 11:28:32 GMT
server: uvicorn
content-length: 29
content-type: application/json

{"error":"Task 99 not found"}
```
